# REFAB Connect Icon Set

Regenerated icon package for the latest REFAB Connect app icon.

Recommended assets folder:
`/public/assets/icons/`

## Main files
- `icon-1024.png` — master app icon
- `icon-512.png` — large app/PWA icon
- `icon-192.png` — standard PWA icon
- `apple-touch-icon.png` — iPhone/iPad home screen icon
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `favicon.ico`
- `favicon-32.png`
- `favicon-16.png`

## HTML example
```html
<link rel="icon" href="/assets/icons/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/assets/icons/favicon-32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/assets/icons/favicon-16.png">
<link rel="apple-touch-icon" href="/assets/icons/apple-touch-icon.png">
<link rel="manifest" href="/assets/icons/site.webmanifest">
```

## Manifest note
The included `site.webmanifest` assumes icons are served from:
`/assets/icons/`

Update the paths if your app uses a different folder.
